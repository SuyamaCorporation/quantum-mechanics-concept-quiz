# Quantum Mechanics Core Concept Quiz

## 概要
量子力学の基礎概念を4択クイズ形式で学べるアプリ。波動関数・不確定性原理・スピン・トンネル効果など52問収録。解説付きで即時フィードバック。

## 機能
- 52問の4択クイズ（10トピック × 3難易度）
- カテゴリフィルター: 波動性/粒子性・シュレーディンガー方程式・不確定性原理・量子数・スピン&パウリ・量子トンネル・測定と波動関数収縮・量子もつれ・原子軌道・エネルギー量子化
- 難易度フィルター: Conceptual（概念）/ Mathematical（数式）/ Advanced（発展）
- 即時フィードバック（正解ハイライト＋詳細解説）
- 正答率・ストリーク・回答数のリアルタイム表示
- 進行状況をlocalStorageで保持

## 使い方
1. カテゴリ・難易度フィルターで出題範囲を選択
2. 4択から答えを選ぶ
3. 即時フィードバックと詳細解説を確認
4. 「Next Question →」で次問へ
